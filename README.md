# SpravaIT

Správa IT v škole – ročníkový projekt.

- **Autor:** Tomáš Pšenek, Timotej Beňo
- **Trieda:** 3.ATL
- **Cieľ projektu:** systém na nahlasovanie a riešenie IT incidentov, evidenciu hardvéru a softvéru, vykazovanie času a mesačné výkazy (pozri `01_Poziadavky/zadanie.md`).

## Postup spustenia aplikácie
Aplikácia zatiaľ nie je implementovaná. Postup spustenia bude doplnený v `06_Dokumentacia/instalacna-prirucka.docx`.

## Štruktúra projektu
- `01_Poziadavky/` – zadanie, roly, funkcionálne a nefunkcionálne požiadavky
- `02_Analyza/` – use case diagram a scenáre
- `03_Navrh/` – ERD, schéma databázy, návrh rozhraní
- `04_Implementacia/src/` – zdrojový kód
- `05_Testovanie/` – testovacie scenáre a zistené chyby
- `06_Dokumentacia/` – používateľská a inštalačná príručka
